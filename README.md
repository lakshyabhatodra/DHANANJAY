# DHANANJAY

## Real-Time Shoulder Surfing Detection System

DHANANJAY is a computer vision-based prototype that detects additional people around a user and raises a potential shoulder-surfing alert.

### Features

- Real-time webcam monitoring
- Face detection using OpenCV
- Face count monitoring
- Threat status indication
- Visual alerts
- Audible alarm
- Activity logging
- Streamlit dashboard

### Tech Stack

- Python
- OpenCV
- Streamlit
- Haar Cascade
- Pygame

### Future Scope

- Person tracking
- Head orientation detection
- Risk scoring
- Smarter threat detection
- Automatic privacy mode
